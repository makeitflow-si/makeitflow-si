### What we build

| Product | What it does |
|---|---|
| **Website audit platform** | Grades any site for speed (Core Web Vitals), SEO, DNS, email deliverability (SPF, DKIM, DMARC), security headers, SSL, accessibility and AI search readiness, with a copy-paste fix for every issue. |
| **151 free tools** | SEO, security, email, DNS, developer, image, PDF and business tools that run in your browser. |
| **Search Console dashboard and rank tracker** | Your real Google and Bing clicks, keywords and quick wins, with a weekly email. |
| **Chrome extension** | A security and privacy inspector for the page you are on. |
| **WordPress plugin** | Health checks from wp-admin, plus the full audit when you connect a free account. |
| **Flows** *(coming soon)* | Trigger → filter → action automations on your website signals: downtime, SSL expiry, score drops, DMARC failures, ranking moves. Sends to Email, Telegram, Slack, Discord, Google Chat or any webhook. |

### Security first

Deep checks run only on sites you have verified as yours. Secrets are stored encrypted, outgoing webhooks are signed, and every scan is rate limited.
